# Architecture decision records

One file per decision, numbered and never deleted. A superseded ADR remains in
place with its new status.

## Template

```markdown
# ADR-NNNN: Title

**Status:** proposed | accepted | amended by ADR-MMMM | superseded by ADR-MMMM
**Date:** YYYY-MM-DD

## Context

What forced the decision.

## Decision

What the project will do.

## Consequences

What becomes easier, harder or deliberately deferred.
```
